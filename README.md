# Frontend Crash Courses Collection

This repository contains beginner-friendly crash courses in key frontend web technologies, all based on excellent tutorials by [Brad Traversy](https://www.youtube.com/user/TechGuyWeb). Each subfolder contains code and notes following a specific course.

## Recommended Learning Order

To get the most out of these tutorials, it's recommended to follow this order:

1. **HTML**
2. **CSS**
3. **JavaScript**
4. **Vue.js**

Each course builds on the previous one to gradually introduce modern frontend development skills.
